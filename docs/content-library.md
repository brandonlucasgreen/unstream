## Workflow: feature ships → post goes live

1. Feature merges to main
2. Marketer drafts platform-specific posts (per voice-and-positioning.md guidelines)
3. Submit drafts for board review
4. Board reviews, edits tone/voice, approves
5. Board schedules via Buffer (Threads, Bluesky, Mastodon, LinkedIn)
6. Post goes live → note in calendar as "Published"
